# Original CPLEX reference results

**[Download GB_tidal_CPLEX_reference_results.zip](GB_tidal_CPLEX_reference_results.zip)** — 13.8 MB, five scenario folders, four hourly CSVs per folder. The 20 files each contain **8,760 rows**. Numerical data and the ZIP have been preserved.

| Folder inside ZIP | Scenario |
| --- | --- |
| `scenario_0/` | Baseline, 597 MW tidal capacity |
| `scenario_1_z1/` | Additional 500 MW tidal in z1 |
| `scenario_2_z9/` | Additional 500 MW tidal in z9 |
| `scenario_3_z15/` | Additional 500 MW tidal in z15, wind substitution in z12; original label `z12_15` |
| `scenario_4_all/` | Additional 500 MW in each of z1, z9 and z15 |

Each folder contains generator dispatch (`pypsa_results_gen.csv`), net storage dispatch (`pypsa_results_stor.csv`), zonal prices (`pypsa_results_marginal_price.csv`) and link flows (`pypsa_results_network.csv`). Power is in **MW**; prices are in **£/MWh**. Snapshot indices are **0–8759**. A one-hour power observation contributes the same numeric value in MWh. Storage is positive when discharging; link `p0` is positive from `bus0` to `bus1`. Column counts differ because inactive zero-capacity generators are omitted in some scenarios.

## Extract the archive

Use your operating system's ZIP tool, or run from this folder:

```sh
python -m zipfile -e GB_tidal_CPLEX_reference_results.zip .
```

Extracted folders are ignored by Git. The [notebooks](../stage2_pypsa/) write new simulations elsewhere and do not overwrite this archive.

## Summarise without a solver

From the repository root, with pandas and NumPy installed:

```sh
python -m pip install pandas numpy
python stage2_pypsa/summarise_results.py
```

The script reads the ZIP directly, checks all 20 CSVs, and reads generator capacities, costs, profiles and demand shares from the notebook syntax **without executing the notebooks**. Neither PyPSA nor CPLEX is required. It writes `scenario_summary.csv` and `zonal_metrics.csv` into the ignored `stage2_pypsa/outputs/reference_summary/` folder. Use `--output-dir PATH` to choose another destination or `--archive PATH` for an archive with the same layout and model configuration. This command summarises supplied outputs; it does not rerun optimisation or regenerate the paper's plots.

The committed [scenario_summary.csv](scenario_summary.csv) was generated by that command. Changes below are scenario minus baseline; negative costs and curtailment are reductions.

## Calculation definitions

- **Operating cost:** sum of hourly generator dispatch × its marginal cost. Import proxies and any load shedding are included, as they are generator components in the objective. Storage has zero marginal cost.
- **RES curtailment:** sum of installed capacity × availability minus dispatch for wind, solar PV and tidal. This uses the supplied profiles and capacities, not a rounded paper coefficient.
- **Average generation cost:** operating cost / total generator output, including import proxies and any load shedding.
- **RES capture price:** generation-weighted zonal marginal price for the combined wind/PV/tidal output; zero production gives an undefined capture price.
- **Weighted market price:** zonal marginal prices weighted by zonal demand over the year.
- **Cost change per added tidal MWh:** two separate columns divide the operating-cost change by the change in available tidal energy and by the change in dispatched tidal energy. The baseline has no added energy, so these cells are blank. These definitions should not be treated as interchangeable SIC estimates.
- **Gas output:** CCGT, CHP, Gas and OCGT combined. **Imports** and **load shedding** are reported separately.

The associated manuscript contains discrepancies in curtailment, SIC and some scenario labels. Read the [consistency notes](../docs/reproducibility.md#consistency-with-the-submitted-paper) when comparing these summaries to Figures 11–12 and Table 5. The figures are retained as submitted, not recalculated.
