# GB Tidal Energy interactive map

This directory contains the complete QGIS/qgis2web map export.
Serve index.html through an HTTP or HTTPS server. All map assets use relative
paths; the OpenStreetMap basemap requires internet access. See the repository
README for local preview instructions, scenarios and data-source information.

Keep the visible OpenStreetMap attribution. Licence information:
https://www.openstreetmap.org/copyright
Tile service policy:
https://operations.osmfoundation.org/policies/tiles/
Use HTTPS, allow the browser's genuine Referer, respect browser caching,
and do not bulk-download or prefetch tiles. No API key is required.
